# Pyxelist
A simple python import that allows you to use list to make images in the turtle screen.

# versions: (version {int}. build {int})
>V0_0.py<br>V0_1.py<br>V0_2.py

# scripts:
>create an object: `thing = pyxelist(int, int, list|dict, int,)`<br>draw the object: `thing.draw()` or `thing.draw(frame=any)`<br>teleport the object the object `thing.set(str, int|tuple)`<br>move the object `thing.move(str, int|tuple)`
